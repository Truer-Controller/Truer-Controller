## Professional Experience

### Financial & Fiscal SaaS Platform

Atuação no desenvolvimento Greenfield de um ecossistema financeiro e fiscal para uma plataforma SaaS.

- Desenvolvimento de APIs utilizando **C# e ASP.NET Core Web API**.
- Implementação de regras de negócio para créditos, parcelamentos e fluxo de caixa.
- Desenvolvimento de integrações bancárias e serviços externos.
- Implementação e evolução do fluxo de emissão de **Nota Fiscal Eletrônica (NFe)**.
- Integração com plataforma responsável pela comunicação com a **SEFAZ**.
- Transformação de dados para os contratos das APIs externas e processamento dos retornos.
- Refatoração do fluxo legado de emissão fiscal, reduzindo acoplamento e complexidade.
- Aplicação de **DDD, Clean Architecture, SOLID, Clean Code e FluentValidation**.
- Modelagem e otimização de banco de dados **SQL Server**.
- Participação na implementação de **Micro Frontend** com autenticação compartilhada (SSO).

### Legacy Systems & Enterprise Applications

Atuação na manutenção, modernização e evolução de sistemas corporativos, incluindo aplicações do segmento hospitalar.

- Desenvolvimento com **C#, ASP.NET, ASP.NET MVC e Web Forms**.
- Modernização e refatoração de funcionalidades legadas.
- Evolução de APIs e integração entre sistemas.
- Otimização de consultas SQL, LINQ e comunicação com banco de dados.
- Implementação de paginação e redução de requisições desnecessárias.
- Ganhos superiores a **90% de performance** em funcionalidades críticas.
- Aplicação de princípios de **SOLID, Clean Code e DDD**.
- Desenvolvimento de relatórios analíticos com **SQL Server e Crystal Reports**.

### AgroTech Marketplace

Participação no desenvolvimento de uma plataforma de marketplace para pequenos e médios produtores rurais.

- Desenvolvimento Full Stack utilizando **PHP, Laravel, JavaScript e MySQL**.
- Desenvolvimento de APIs e funcionalidades de Backoffice.
- Implementação de interfaces a partir de protótipos do Figma.
- Desenvolvimento de chat em tempo real utilizando **Pusher, eventos e filas do Laravel**.
- Integração entre Front-end e Back-end.
- Otimização da comunicação entre aplicação e APIs.
- Aproximadamente **40% de melhoria de performance** em fluxos da aplicação.
